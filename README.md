# 影匣

安卓手机上的影视客户端。本仓库只用于发布安装包，源码在私有仓库维护。

## 下载

- 最新版本：[yingxia.apk](https://github.com/xiaotaitech/yingxia-release/releases/latest/download/yingxia.apk)
- 所有版本与更新说明：[Releases](https://github.com/xiaotaitech/yingxia-release/releases)

要求 Android 8.0 及以上。首次安装需要允许浏览器或文件管理器"安装未知应用"。

## 使用

- 影匣**不内置任何内容源**。首次打开后通过扫码、打开配置文件、输入配置地址或在线查找导入配置，也可以手动添加苹果 CMS 接口站点。
- 已安装的用户可在「我的 → 检查更新」中直接更新；「我的 → 分享影匣」可以把下载页二维码或安装包发给朋友，「我的 → 分享配置」把你的配置发过去。
