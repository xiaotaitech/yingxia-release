# 影匣

安卓手机上的影视客户端。本仓库只用于发布安装包，源码在私有仓库维护。

## 下载

- 最新版本：[yingxia.apk](https://github.com/xiaotaitech/yingxia-release/releases/latest/download/yingxia.apk)
- 所有版本与更新说明：[Releases](https://github.com/xiaotaitech/yingxia-release/releases)

要求 Android 8.0 及以上。

## 安装与使用说明

**[使用帮助（HELP.md）](HELP.md)**：包括小米、华为、OPPO、vivo 等手机安装时各种拦截提示的处理方法、导入配置、看片、追剧、分享给朋友和常见问题。应用内「我的 → 使用帮助」是同一份内容。

影匣**不内置任何内容源**，首次打开后需要先导入配置或手动添加站点。

## 反馈

使用中的问题请在 [Issues](https://github.com/xiaotaitech/yingxia-release/issues) 中反馈。
